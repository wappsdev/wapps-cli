Frozen API and meanings
-----------------------
Provider::{Claude,Codex}: exact lower-case source names, no worker model choice.
ReportStatus::{Completed,Failed,TimedOut,Cancelled}: body.rs REPORTED_STATUSES.
Not job state: rejected and orphaned cannot be reported; a completed report may
leave a cloud row review_pending or failed (finish_locked). No job-state machine
or review policy is duplicated here.
SecretMaterial::new(String): nonempty, opaque, unchanged capability bytes.
No assumed base64 format, trimming, raw getter, Display, or generic Serialize.
LeaseAuthority::new(SecretMaterial,u64): capability plus public fencingToken,
1 through 9007199254740991 inclusive (body.rs check_int). This constructor is not
a JSON-number parser: codecs must preserve the core's integral-number semantics,
including integral decimal notation, rather than imposing serde u64 parsing.
JobAuthority::new(String,SecretMaterial): jobId plus capability, no epoch.
jobId uses JavaScript trim and 1..128 UTF-16 units (body.rs JOB_AUTHORITY).
No lease/job conversion exists. job_id() and fencing_token() expose metadata.
wire() returns a distinct borrowed typed view: LeaseAuthorityWire serializes
{capability,fencingToken}; JobAuthorityWire serializes {jobId,capability}.
Only these explicit authority-bearing wire views implement Serialize. Debug
redacts both views and owning authority; even an untrusted job id is omitted.
ContractError retains no rejected input, and diagnostics/error serialization
contain only fixed categories. This is containment, not memory zeroization.
CloudError::{Transport,Http{status},Protocol,Rpc,Refused} retains no request,
URL, arbitrary message, response body, recovery text, or nested provider error.
RPC is category-only: the bridge accepts integral numbers beyond i64, so no
narrower code representation is frozen. No cloud refusal/code mapping table is
copied. outcome() is Refused only for a known nonmutating schema/auth/domain
refusal; bare HTTP status, protocol/RPC failure, and transport failure are
Unknown. Generic isError or an INTERNAL envelope is not proof of no mutation.
This contract makes no retry decision or network request.

Reuse and integration boundary
------------------------------
Existing serde and serde_json suffice; no dependency is added. The CLI bridge
uses dynamic Value/string errors, and the platform's public dynamic authority
has secret-bearing Debug/Serialize, so neither is an adequate safe owning type
for this separate native component. The cloud's schema/policy remains cloud-owned.
No provider payload, role registry, quota schema, or outbound scrub algorithm is
invented here. Codecs can encode typed wire views and use categorical errors;
scrub/quota consumers can share Provider without importing a runtime.
Integration blockers intentionally remain unresolved: project/provider context,
role policy, review independence, role registry filesystem layout, credentials,
model defaults, native adapter provenance, and HTTP retries. Source changes do
not establish that platform feefd2d is deployed. No provider/cloud execution,
real stores, credentials, configuration changes, deployment, release, push,
migration, or primary-checkout edit was performed.
