src/process/quota.ts (complete, 100 lines):
- Claude utilization is a fraction, always multiplied by 100. Codex
  used_percent is already percent, even when it is 1 or less.
- Round with JavaScript Math.round semantics, then clamp to [0, 100]. Only
  numeric finite usage values qualify; strings, booleans, null, and missing
  values produce a status-only reading, not coercion.
- Claude rejected and allowed_warning override inferred status. Other status
  words use the percentage threshold of 90. Codex infers status from percent.
- Claude rateLimitType is preserved verbatim, including an empty string.
  Codex uses primary only, never secondary. At least 1440 minutes selects days;
  shorter windows select hours. Division is rounded, not floored.
- Both reset fields are raw Unix seconds. Negative, fractional, zero, expired,
  and implausibly large finite numeric resets are retained without conversion,
  freshness filtering, or guessing whether the provider supplied milliseconds.
- Truthy malformed info/primary values (arrays, objects, nonempty strings,
  true, and nonzero numbers) still produce a reading with absent fields. Falsy
  values (null, false, zero, and empty string) do not. This preserves source
  behavior rather than imposing a stricter schema.

src/process/codex_mcp.ts:89-149:
- Admit only the source's 12 watched event types from method codex/event,
  params.msg. Borrow that exact message without transformation or cloning.
- Drop unknown events, agent_message_content_delta and raw_response_item.
- token_count is admitted even when it carries no primary quota reading.

src/process/runtime.ts:447-479:
- Read quota before classifying noise.
- Suppress recording and progress ONLY if quota extraction returned a reading
  and the payload's type is token_count. Claude quota messages, unrecognized
  direct messages, and counters without quota are not suppressed.
- Event admission and runtime message classification are separate functions;
  classify_message does not reinterpret unknown events as progress noise.

Reading diagnostics never retain the input payload and redact the untrusted
window string in Debug, including when nested in ParsedMessage. Serialize is
an explicit data representation, not a credential-safe diagnostic format.
The JSON Value domain excludes NaN and infinity; overflow from multiplying a
finite Claude fraction is nevertheless correctly clamped to 100.
